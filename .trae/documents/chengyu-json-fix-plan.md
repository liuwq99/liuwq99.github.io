# 成语 JSON 文件修正工作计划

## 一、任务概述

对 `source/src/views/home/data/chengyu` 目录下的成语 JSON 文件进行批量修正,共涉及 31 个 group JSON 文件(约 683 个成语)。

## 二、当前状态分析

### 2.1 文件清单
- **JSON 文件**: 31 个(group-1.json 至 group-31.json)
- **成语总数**: 约 683 个
- **索引文件**: index.json(不需要修改)

### 2.2 数据结构
每个成语对象包含以下字段:
```json
{
  "word": "成语",
  "explain": "解释",
  "pinyin": "拼音(需要修正)",
  "origin": "出处(需要清空)",
  "sentence": ["例句数组"],
  "easy": ["记忆技巧数组(需要重新编写)"],
  "wrongCount": 0,
  "category": "分类",
  "type1": "类型"
}
```

### 2.3 存在的问题
1. **pinyin 字段不匹配**: 当前拼音与成语不对应(如"源远流长"的拼音写成"bá miáo zhù zhǎng")
2. **origin 字段不一致**: 部分为空字符串,部分有具体出处
3. **easy 字段不完整**: 部分成语已有记忆技巧,部分为空数组
4. **JSON 格式风险**: sentence 和 explain 字段包含中文双引号,需确保不被误改为英文双引号

## 三、修正方案

### 3.1 pinyin 字段修正
- **原则**: 为每个成语查找正确的拼音
- **格式**: 使用空格分隔的带声调拼音(如 "yuán yuǎn liú cháng")
- **执行方式**:
  - 使用在线拼音查询工具或字典 API
  - 人工核对每个成语的拼音
  - 逐文件批量修正

### 3.2 origin 字段清空
- **目标**: 所有 origin 字段统一设置为空字符串 `""`
- **执行方式**: 批量替换

### 3.3 easy 字段编写
- **原则**:
  - 创作幽默、夸张、易记的记忆技巧
  - 可以使用故事化、场景化的描述
  - 突出成语的关键特征或典故
- **示例**:
  - "守株待兔": "农夫守在树桩旁等兔子撞上来——死守老办法,不知变通,坐等机会送上门。"
  - "刻舟求剑": "楚人剑掉水里,在船边刻记号说'剑是从这掉的'——不懂事物在变化,死守旧经验。"

### 3.4 JSON 格式保护
- **关键点**: 确保 sentence 和 explain 字段中的中文双引号 `""` 不被误改为英文双引号 `""`
- **措施**:
  - 使用支持 JSON 格式的编辑器
  - 修正后进行 JSON 格式验证
  - 编写验证脚本检查 JSON 有效性

2. **内容抽查**

   - 检查拼音是否正确

## 六、风险与注意事项

### 6.1 主要风险
1. **JSON 格式错误**
   - 中文双引号被误改为英文双引号
   - 编码问题导致乱码
   - 遗漏逗号或括号

2. **拼音错误**
   - 多音字处理不当
   - 声调标注错误

3. **内容质量**
   - easy 字段记忆效果不佳
   - 内容过于生硬或不够幽默

### 6.2 应对措施
1. **JSON 格式保护**
   - 修正前后都进行格式验证
   - 使用版本控制,便于回滚

2. **拼音校对**
   - 使用权威拼音字典
   - 对多音字进行人工核对

3. **内容审核**
   - 编写完成后进行自查
   - 必要时请他人协助审核
