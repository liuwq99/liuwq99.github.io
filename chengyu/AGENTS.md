# 项目协作说明

## 项目概况

这是一个以中文成语/实词学习资料为核心的小型数据处理与静态网页项目。根目录包含从 PDF 提取的文本、按组整理的 JSON 数据，以及用于生成背词日历的静态页面。

- `17day/index.html`：独立运行的浏览器页面，展示“GRE 17天背词计划表”，无构建框架或外部依赖。
- `index.html`：背词/刷题学习页（根目录），参考百词斩交互：下拉选择词库后进入“背题模式”（逐词展示拼音、解释、例句、记忆方法）或“刷题模式”（先显示词和拼音，点“查看答案”后展开详情）。单文件、零依赖，通过 `<script src="data.js">` 读取数据，双击即可打开。
- `data.js`：由 `build_data_js.js` 生成的静态数据文件，包含 `window.CHENGYU_DATA`（29 个词库包，每包含 `key`、`label`、`来源`、`说明`、`groups`、`count`；词条字段为 `词`、`拼音`、`解释`、`例句`、`记忆方法`、`组别`）。**不要手工编辑**。
- `build_data_js.js`：Node 脚本，遍历 `data/*.json` 合并生成根目录 `data.js`。新增或修改 JSON 后运行 `node build_data_js.js` 重新生成。
- `build_json.py`：从 `/tmp/up_utf8.txt` 提取指定成语组并生成 JSON；包含辅助记忆方法映射。
- `build_json.js`：Node.js 版本的数据生成脚本，读取根目录 `up_utf8.txt`。
- `update_json.js` / `update_json.py`：为 JSON 词条统一补充 `拼音`、`记忆方法` 字段的脚本（依赖 `node_modules/pinyin-pro`）；成语用 `记忆方法`，实词原本的 `记忆技巧` 已统一改名为 `记忆方法`。
- `data/*.json`：已整理的成语/实词分组数据（29 个文件，成语 826 条、实词 151 条，共 977 条）。词条字段：`成语`或`实词`、`拼音`、`解释`、`完整例句`、`记忆方法`。
- `up_utf8.txt`、`down_utf8.txt`：从上下册资料提取的 UTF-8 文本。
- `*.pdf`：原始学习资料。

## 常用操作

项目没有 `package.json`、测试框架或统一构建配置。网页可直接用浏览器打开 `17day/index.html`，也可在根目录启动任意静态文件服务器后访问。

重新生成第一至四组成语数据时：

- Python：`python build_json.py`（要求存在 `/tmp/up_utf8.txt`，脚本会写入根目录的 `第一至四组成语.json`）。
- Node.js：`node build_json.js`（要求根目录存在 `up_utf8.txt`，同样覆盖生成 `第一至四组成语.json`）。

修改后至少应在浏览器中手动验证页面加载、批次添加/删除、日期和时间输入、计划生成及月份切换；数据生成脚本应检查输出 JSON 可解析且分组数量符合预期。

## 编辑约定与注意事项

- 页面、界面文案和数据字段以中文为主；保持现有中文命名和格式风格。
- `17day/index.html` 是单文件应用：HTML、CSS、JavaScript 均在同一文件内，除非确有需要不要引入构建工具或外部依赖。
- 日程计算使用浏览器本地时间；“12小时后”在跨午夜时会把复习日期顺延一天。修改日期逻辑时要保留这一行为，并注意 `[0, 1, 2, 4, 7, 15]` 间隔的含义。
- 页面默认日期、时间和批次写在脚本末尾；调整默认展示时同步确认自动生成逻辑。
- 生成脚本会覆盖 JSON 文件，编辑或运行前确认输入文本路径和输出文件范围，避免误覆盖原始 PDF/文本资料。
- JSON 使用 UTF-8 和中文原文（不转义 ASCII）；保持现有字段：`成语`、`解释`、`完整例句`、`记忆方法`，以及分组层级结构。
- 这是资料整理项目，未配置 Git 仓库或自动化 CI；不要假设存在 lint、typecheck 或单元测试命令。
